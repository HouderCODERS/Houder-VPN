# 🌐 HouderVPN

### Simple VPN Client for Windows

**HouderVPN** is a simple VPN client designed to make connecting to available VPN servers easy and convenient.

Choose a server, press **START**, and manage your connection through a straightforward interface.

## 🛠️ Installation Guide

Follow these steps to install HouderVPN on Windows.

### Step 1 — Download the Archive

1. Open the [HouderVPN Releases](https://github.com/HouderCODERS/Houder-VPN/releases) page.
2. Find the latest release.
3. Open the **Assets** section.
4. Download the HouderVPN `.rar` archive.
5. Wait until the download is complete.

### Step 2 — Extract the Archive

1. Locate the downloaded `.rar` file.
2. Open it using WinRAR or another archive extraction program.
3. Extract all files into a folder.
4. Open the extracted folder.

### Step 3 — Run the Installer

1. Find the HouderVPN installer.
2. Run the installer.
3. Follow the instructions displayed on the screen.
4. Wait for the installation to finish.
5. Launch HouderVPN.

### Step 4 — Connect

1. Open HouderVPN.
2. Select your preferred server.
3. Press **START**.
4. Wait for the connection process to complete.

That's it! You can now use the application.

## 🧰 Troubleshooting

### The Application Does Not Start

- Make sure the installation completed successfully.
- Check that all archive files were extracted.
- Restart the application.
- Check that your Windows version is supported.

### The Installer Does Not Open

- Make sure the `.rar` archive was extracted.
- Try extracting the archive again.
- Check that the downloaded archive is not damaged.

### The VPN Connection Does Not Start

- Check your internet connection.
- Select another available server.
- Try restarting HouderVPN.
- Check whether the selected server is online.

### The Connection Is Unstable

- Try another server.
- Check your internet connection.
- Make sure the selected server is available.
