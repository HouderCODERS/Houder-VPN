# 🌐 HouderVPN

**A simple VPN client designed for an easy and convenient connection to available VPN servers.**

HouderVPN provides a straightforward interface where users can select a server and start a connection with just one click.

## 📥 Installation Guide

Follow these steps to install HouderVPN on your computer.

### Step 1 — Download

1. Open the HouderVPN download page.
2. Download the `.rar` archive.
3. Wait until the download is complete.

### Step 2 — Extract the Archive

1. Find the downloaded `.rar` file.
2. Open it using WinRAR or another archive extraction program.
3. Extract all files into a folder on your computer.
4. Open the extracted folder.

### Step 3 — Run the Installer

1. Find the HouderVPN installer inside the folder.
2. Run the installer.
3. Follow the installation instructions displayed on the screen.
4. Wait until the installation is complete.
5. Launch HouderVPN.

### Step 4 — Connect to a Server

1. Open HouderVPN.
2. Select your preferred server from the server list.
3. Press the **START** button.
4. Wait for the connection process to finish.
5. Once connected, you can use the VPN connection.

## 🛠️ Troubleshooting

### The application does not start
- Make sure the installation completed successfully.
- Check that your system meets the application's requirements.
- Try restarting the application.

### The connection does not start
- Check your internet connection.
- Try selecting another available server.
- Check whether the selected server is online.

### The installer does not open
- Make sure the archive was extracted completely.
- Check that you are launching the installer from the extracted folder.
- Download the archive again if it appears damaged.
